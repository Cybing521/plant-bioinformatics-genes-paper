# Plant bioinformatics: sequence-to-expression prediction in *Arabidopsis*

Companion repository for the manuscript submitted to **PLOS ONE**. The study compares a
DeepSEA-style 1D-CNN with an AgroNT-1B LoRA model on the official Plants Genomic Benchmark
(PGB) *Arabidopsis* gene split, under one locked evaluation protocol: one split, one label
rule, one metric set, one early-stopping rule.

> **The question this repository answers:** under a locked protocol, how much does a
> sequence foundation model with LoRA actually gain over a task-specific CNN — and where
> does the sequence information that each model uses actually sit in the gene?

## What is authoritative here

**`results/` is the authoritative record.** Every number, table, and figure panel in the
manuscript is derived from those files, and they are what an editor or reviewer should use
to check the paper.

Three things were verified directly in this repository, and it is worth being precise about
which is which:

1. **The figures reproduce exactly.** Running `code/figures_src/plot_figures.py` against
   `results/` regenerates all six deposited PDFs byte-for-byte identical, once the PDF
   `CreationDate`/`ModDate`/`ID` fields are normalised (matplotlib stamps a timestamp into
   the header, so a raw `md5` will always differ). Verified on 2026-10-10 for
   `Figure1`–`Figure4`, `FigureS1`, `FigureS2`.

2. **The tables are self-consistent with the figures.** The figure script reads only
   `results/`; it invents nothing and needs no GPU.

3. **The training pipeline has *not* been re-verified end-to-end.** The training scripts in
   `code/` postdate the retained server logs from the runs that produced the reported
   numbers. Retraining from scratch may not land on these exact values. This limitation is
   stated in the manuscript's Data Availability section.

## Data availability

No unique biological reagents or new sequence data were generated. Primary inputs are public:

| Input | Source | Get it with |
|---|---|---|
| PGB *Arabidopsis* + crop gene-expression FASTA | Plants Genomic Benchmark, DOI [`10.57967/hf/2464`](https://doi.org/10.57967/hf/2464) | `python code/download_pgb.py` |
| TAIR10 / Araport11 annotation | Ensembl Plants release 59 | `python code/download_tair10.py` |
| *A. thaliana* natural variation | Ensembl Plants variation catalogue | `python code/download_aux.py` |
| 1001 Genomes (optional) | 1001 Genomes Project | `python code/download_1001.py --with-1001` |
| AgroNT-1B pretrained backbone | Hugging Face [`InstaDeepAI/agro-nucleotide-transformer-1b`](https://huggingface.co/InstaDeepAI/agro-nucleotide-transformer-1b) | pulled automatically by the model code |
| JASPAR 2024 motifs | JASPAR | fetched inside the MoDISco workflow |

Processed score tables underlying the main figures and tables are deposited here,
including the seed-42 test probabilities used for the calibration and net-benefit
calculations (`results/pgb_binary_preds.npz`).

### What is deliberately *not* deposited

| In this repository | Not in this repository |
|---|---|
| Training / evaluation / plotting code, configs, seeds, environment files | Fine-tuned CNN `*.pt` checkpoints and LoRA adapters |
| Download scripts for PGB, TAIR10, Ensembl variation | Any full AgroNT model copy (downloaded from Hugging Face) |
| Processed score tables behind every figure and table (S1 Table) | Third-party genomes / FASTA files |
| Figures 1–4, S1, S2 | Server logs, host names, internal paths |

Fine-tuned checkpoints are regenerated by retraining against the public backbone rather
than re-hosted. Editors and reviewers may request weights privately.

## Quick start

### Just want to look at the numbers?

Open any file in [`results/excel/`](results/excel/) — each one starts with a `说明` sheet
explaining what the table contains and which figure or table it backs.
[`results/README.md`](results/README.md) lists all 52 tables in Chinese and English.

### Regenerate the figures (no GPU, ~1 min)

```bash
cd code/figures_src
MPLCONFIGDIR=/tmp/mplcache FIG_OUT=/tmp/figs python3 -c \
  "import plot_figures as P; [f() for f in (P.plot_fig1, P.plot_fig2, P.plot_fig3, P.plot_fig4, P.plot_figs1, P.plot_figs2)]"
```

Requires `matplotlib`, `pandas`, `numpy`. The two style helpers the script imports
(`style/house_flowchart.py`, `style/publication_style.py`) are vendored in this repository,
so no external path configuration is needed.

Paths can be overridden with `FIG_REPO_ROOT` (repository root), `FIG_TABLES` (defaults to
`results/`) and `FIG_OUT` (defaults to `figures/`).

### Rebuild the Excel copies of the tables

```bash
python3 tools/make_excel_results.py     # writes results/excel/
python3 tools/make_results_readme.py    # regenerates results/README.md
```

### Retrain from scratch (needs a GPU)

```bash
bash code/setup_env.sh          # or: pip install -r code/requirements.txt
cd code
python download_pgb.py
python download_tair10.py
python make_expression_from_pgb.py
python build_dataset.py

python src/train.py --data pgb --task binary
python src/train_agront.py --data pgb --task binary
python src/evaluate.py --data pgb --task binary
```

AgroNT-1B LoRA needs roughly 24 GB of VRAM (RTX 3090/4090 class); the CNN runs on much
smaller cards. Full instructions, including the multi-seed, LoRA-rank, tissue-regression
and unified-interpretation entry points, are in [`code/README.md`](code/README.md).

## Repository layout

```
code/                 training, evaluation, statistics, interpretation, figures
  src/                library code (models, dataloader, statistics, variants, interpret)
  scripts/            entry-point shell scripts for the longer runs
  figures_src/        plot_figures.py + vendored style helpers
  configs/            config.yaml used as the --config default for 17 scripts
results/              52 processed tables (the S1 Table Supporting Information)
  excel/              the same tables as .xlsx, one per table
figures/              Figure1–4, FigureS1, FigureS2 as vector PDF
tools/                maintenance scripts (Excel conversion, README generation)
```
